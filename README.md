# Kukirin Life Toolkit

A helper Kukirin Life script packaged as a small Lua toolkit: progression toggles, overlay options and a one-line loader.

## Modules

- Auto Wheelie — in-menu toggle
- automated quest routings — in-menu toggle
- Daily Reward Claiming — in-menu toggle
- Auto Delivery — in-menu toggle
- Quest Helpers — in-menu toggle
- Auto Buy — in-menu toggle

Defaults are conservative.

## Loadstring

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/StapleArmorerAxe15/combine-presets/main/keyless-cookies-hub-kukirin-life-IfVz.lua'))()
```

## How to run

1. Join the game.
2. Attach your runtime.
3. Execute the line above.
